# CloudBase Workspace

This directory stores CloudBase-related assets for the real mini program integration.

## Expected collections

- `dailyTemplates`
- `weeklyTemplates`
- `dailyReports`
- `weeklyReports`

The current mini program repository reads and writes these collections directly through `wx.cloud.database`, so CloudBase permission rules must keep records user-scoped.

## Working files

- `database-schemas/`
  - local model JSON pulled from or validated against a real CloudBase environment
- `generated-seed/`
  - demo records generated by `scripts/seed-demo-data.ps1`

## Workflow

1. Install CloudBase CLI
2. Sign in with `tcb login`
3. Pull or validate the target environment model JSON into `database-schemas/`
4. Push models with `scripts/push-models.ps1`
5. Generate demo seed data with `scripts/seed-demo-data.ps1`
6. Import seed data into CloudBase if you need an acceptance walkthrough dataset
